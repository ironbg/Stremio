# Site Launcher — модул за TizenBrew / приложение за Samsung Tizen TV

Отваря избрани сайтове на цял екран. Сайтовете се добавят и настройват директно от телевизора с дистанционното. Поддържа Tizen 3.0+.

## Функции
- Списък със сайтове като плочки, навигация със стрелките
- Добавяне, редакция и изтриване от телевизора
- Два режима на отваряне: **вграден** (BACK се връща към списъка) и **директен** (за сайтове, които забраняват вграждане)
- Автоматично отваряне на избран сайт при стартиране
- Настройваем таймаут; ако сайтът не се зареди, се предлага директно отваряне
- Данните се пазят в `localStorage`

| Стрелки | избор на плочка | между полетата | към сайта |

| 🔴 Червен | добави сайт | — | — |
| 🟢 Зелен | редактирай | — | — |
| 🟡 Жълт | изтрий | — | — |
| 🔵 Син | настройки | — | — |

## Структура
```
package.json        — описание на TizenBrew модула (packageType: "app")

icon.png
app/
  index.html        — екрани: списък, редактор, настройки, плейър
  css/style.css     — оформление за 1920×1080
  js/storage.js     — съхранение на сайтове и настройки
  js/nav.js         — пространствена навигация с дистанционното
  js/main.js        — логика на екраните и бутоните
```

## Инсталиране

### Вариант А: TizenBrew от GitHub (като StremioK)
1. Хранилище: `ironbg/Stremio` (публично).
2. В TizenBrew: **MENU › Add GitHub module** → въведи `ironbg/Stremio`.
3. Стартирай **Site Launcher** от списъка с модули.

### Вариант Б: TizenBrew от NPM
1. `npm login` и `npm publish` от папката на проекта (името в `package.json` трябва да е свободно).
2. В TizenBrew: **MENU › Add NPM module** → `site-launcher-tv`.

### Вариант В: самостоятелно приложение (.wgt)
1. Tizen Studio → Import › Tizen Project → избери папката.
2. Certificate Manager → Samsung сертификат за TV.
3. Свържи телевизора в Device Manager → Run As › Tizen Web Application.

CLI:
```
tizen package -t wgt -s <профил> -- .
tizen install -n SiteLauncher.wgt -t <телевизор>
```

## Ограничения
- Сайтове с `X-Frame-Options` или CSP `frame-ancestors` не се отварят във вграден режим — използвай директен.
- В директен режим BACK се обработва от сайта/системата; за връщане към списъка рестартирай приложението.
